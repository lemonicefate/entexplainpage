# Allow mixed information densities without page modes

An education sequence may freely mix illustrated explanations with dense tables, codes, thresholds, and rule summaries in the explicit order chosen by its content editor. These are layout and capacity differences rather than audience modes: dense rule pages may intentionally be shown to patients as evidence that a recommendation follows defined rules, so the system does not split sequences or add patient/clinical mode labels; every page still obeys the shared square canvas and brand frame.
