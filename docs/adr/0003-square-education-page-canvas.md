# Use a square canvas for education pages

Education pages use a 1:1 standard canvas because the same rendered page must work both in the desktop-first clinic player and on square-first social channels such as Instagram. This deliberately accepts unused horizontal space on widescreen clinic displays in exchange for one reusable composition and no second social-specific aspect ratio to maintain; content variation belongs inside each topic's approved AI visual master rather than alternate page dimensions.
