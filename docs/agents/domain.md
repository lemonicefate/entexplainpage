# Domain docs

This repository uses a single domain context.

## Before exploring

- Read root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that affect the work.
- If either location is absent, proceed without creating placeholder docs.

## Vocabulary

Use the terms defined in `CONTEXT.md` in tickets, tests and design work.
Respect terms listed under “Avoid”.

If required terminology is missing, reconsider whether a new domain concept
is actually needed; use domain-modeling when it is.

## Architecture decisions

Surface conflicts with existing ADRs explicitly. Do not silently override
an ADR.
